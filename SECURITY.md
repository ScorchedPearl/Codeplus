# Security policy

The site has a members-only admin panel and stores member accounts, so we take security reports seriously.

## Reporting a vulnerability

**Please don't open a public issue.** Instead, email **codeplus@iiita.ac.in** with:

- what the problem is and where (page or file)
- steps to reproduce it
- what an attacker could do with it

We'll reply as soon as we can and keep you updated while we fix it. Please give us a reasonable amount of
time to fix the issue before sharing it publicly.

## Out of scope

- Testing against the live site in ways that could affect real users or data (load testing, spam, brute-forcing logins)
- Reports that only apply to your own local setup
