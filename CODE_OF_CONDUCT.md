# Code of Conduct

CodePlus is a teaching club: people come here to learn, often while they're just starting out.
We want this project to be a welcoming place for everyone, whatever their experience level.

## Expected behaviour

- Be kind and patient, especially with beginners. Everyone was one once.
- Give constructive feedback on code, not on people.
- Assume good intent and ask before assuming.
- Respect people's time, privacy and differing opinions.

## Not acceptable

- Harassment, insults or discriminatory jokes and language
- Personal or political attacks
- Publishing anyone's private information (phone numbers, addresses, etc.) without permission
- Any other conduct that would be inappropriate in a classroom

## Enforcement

CodePlus coordinators maintain this project and may remove comments, commits, issues or pull requests
that break this code, and may block repeat offenders.

Report problems privately to **codeplus@iiita.ac.in**. Reports are handled confidentially.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.
